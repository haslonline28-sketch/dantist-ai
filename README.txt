ДАНТИСТ — ДЕМО-ПРОЕКТ

index.html — готовый интерфейс чата.
server.mjs — серверный шаблон для подключения OpenAI.

ВАЖНО:
1. Не вставляйте API-ключ в index.html.
2. API-ключ должен храниться только на сервере в OPENAI_API_KEY.
3. Prompt ID уже указан в server.mjs.
4. Перед публикацией проверьте, что ваш опубликованный Prompt и MCP/Google Calendar
   разрешены для выбранного способа API-вызова.

Следующий шаг — разместить проект на сервере/хостинге и настроить OPENAI_API_KEY.
